# 完善 Auth 接口 Swagger 文档与端到端测试

## 1. 定义响应数据传输对象 (DTO)
在 `src/routes/auth/dto/auth.dto.ts` 中添加以下 DTO，以便在 Swagger 中清晰展示返回数据结构：
- **`LoginResponseDto`**: 描述登录成功后的 Token 返回结构。
- **`UserResponseDto`**: 描述用户信息结构（避免直接使用未加装饰器的 Model）。
- **`UserInfoResponseDto`**: 描述 `/auth/info` 接口的返回结构，包含 `user`、`roles`、`permissions`。
- **`RouterResponseDto`**: 描述 `/auth/routers` 接口返回的菜单路由结构。

## 2. 更新 AuthController 文档
修改 `src/routes/auth/auth.controller.ts`：
- 引入新定义的 DTOs。
- 为 `login`、`info`、`routers` 接口的 `@ApiResponse` 装饰器添加具体的 `type` 描述。
- 确保所有接口都有清晰的 `summary` 和返回类型说明。

## 3. 完善端到端 (E2E) 测试
修改 `test/app.e2e-spec.ts`，在 `Auth` 测试组中增加以下测试用例：
- **`GET /auth/info`**:
    - 测试未登录访问（预期 401）。
    - 测试登录后访问，验证返回状态码 200 及数据结构（包含 user, roles, permissions）。
- **`GET /auth/routers`**:
    - 测试未登录访问（预期 401）。
    - 测试登录后访问，验证返回状态码 200 及路由菜单数据。

## 4. 验证
- 运行测试命令 `npm run test:e2e` (或 `pnpm test:e2e`) 确保所有测试通过。
