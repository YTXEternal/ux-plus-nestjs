# 新增“检查路由是否存在”接口计划

## 1. 修改 System Menu Service
**文件**: `src/routes/system/menu/sys-menu.service.ts`
- 新增 `checkRouteNameUnique` 方法。
- 逻辑：查询数据库中是否存在指定 `route_name` 的菜单记录。为了保证名称唯一性，将检查所有状态的菜单。

## 2. 修改 Route Service
**文件**: `src/routes/route/route.service.ts`
- 新增 `isRouteExist` 方法。
- 逻辑：调用 `SysMenuService.checkRouteNameUnique` 并返回布尔值。

## 3. 修改 Route Controller
**文件**: `src/routes/route/route.controller.ts`
- 新增 `GET /route/isRouteExist` 接口。
- 参数：通过 `@Query` 获取 `routeName`。
- 响应：返回 `ApiResponse<boolean>`，其中 data 为 `true` 或 `false`。
- 添加 Swagger 文档注解 `@ApiOperation` 和 `@ApiQuery`。

## 4. 端到端测试
**文件**: `test/app.e2e-spec.ts`
- 新增针对 `/route/isRouteExist` 的测试用例：
    - 检查存在的路由名称（预期返回 true）。
    - 检查不存在的路由名称（预期返回 false）。
    - 检查未鉴权访问（预期返回 401）。
