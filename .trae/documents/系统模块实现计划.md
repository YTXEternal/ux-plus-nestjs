# 系统模块实现计划

根据您的需求和 `SYSTEM_MODULES_DESIGN.md` 文档，我将为您实现整套系统管理模块。

## 1. 准备工作与清理
为了避免冲突，我们将清理旧的业务代码和数据库表。
- **清理旧模块**：删除 `src/routes/registry`，`src/routes/registry-code` 等旧的注册/登录模块。
- **清理旧模型**：删除 `Registry`, `RegistryCode`, `Test`, `Users` 等旧的 Sequelize 模型。
- **依赖确认**：
  - 文档中涉及 Excel 导出/导入功能，需要引入 `exceljs` 或 `xlsx` 库。**请确认是否允许安装 `exceljs`**。
  - 文档中涉及 User Agent 解析（登录日志），建议引入 `ua-parser-js`。**请确认是否允许安装**。
  - 密码加密将采用文档中示例的 **Bcrypt** 方案（对应 `bcryptjs` 库，已存在于项目中），替代原有的 RSA/MD5 方案以符合设计文档的数据库结构。

## 2. 数据库实现 (MySQL)
我们将严格按照文档创建数据库表。
- **创建模型文件** (`src/databases/mysql-database/model/`)：
  - `SysUser` (用户)
  - `SysRole` (角色)
  - `SysMenu` (菜单)
  - `SysDept` (部门)
  - `SysPost` (岗位)
  - `SysDictType` / `SysDictData` (字典)
  - `SysConfig` (参数)
  - `SysNotice` (通知)
  - `SysOperLog` / `SysLogininfor` (日志)
- **执行 SQL 建表**：
  - 使用 MCP 工具执行文档中提供的 SQL 语句，创建表结构并插入初始数据（如管理员账号、初始菜单）。

## 3. 模块功能实现
将在 `src/routes/system/` 和 `src/routes/monitor/` 下创建对应的模块。

### 3.1 系统管理 (`/system`)
- **用户管理 (`SysUserModule`)**：实现增删改查、导入导出、重置密码、分配角色。
- **角色管理 (`SysRoleModule`)**：实现角色增删改查、数据权限、分配菜单。
- **菜单管理 (`SysMenuModule`)**：实现菜单树形结构、增删改查。
- **部门管理 (`SysDeptModule`)**：实现部门树、增删改查。
- **岗位管理 (`SysPostModule`)**：实现岗位管理。
- **字典管理 (`SysDictModule`)**：实现字典类型和数据的管理。
- **参数设置 (`SysConfigModule`)**：实现系统参数配置。
- **通知公告 (`SysNoticeModule`)**：实现公告发布与管理。

### 3.2 系统监控 (`/monitor`)
- **操作日志 (`SysOperLogModule`)**：记录和查询操作日志。
- **登录日志 (`SysLogininforModule`)**：记录登录历史、账户解锁。
- **在线用户 (`SysOnlineModule`)**：
  - 使用 **Redis** 存储在线用户 Token。
  - 实现强退用户功能。

## 4. 核心服务调整
- **认证服务 (`AuthModule`)**：
  - 更新登录逻辑，对接 `sys_user` 表。
  - 使用 `bcryptjs` 进行密码比对。
  - 集成 `ux-jwt` 生成 Token。
- **权限守卫**：
  - 更新守卫以支持新的权限标识（如 `system:user:list`）。

- 确认所有表结构创建正确。
- 确认初始数据导入成功。
- 验证核心接口（登录、用户列表、菜单树）可用。
