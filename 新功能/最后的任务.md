# 关于购票和购票记录涉及的支付和退款

- 使用支付宝沙箱模拟扫码支付以及退款操作
- 并且关于支付成功和支付失败都应该有相关记录反馈到支付宝沙箱中
- 关于需要填入支付宝沙箱的一些参数可以放在.env文件中让我能够填写（你在使用的时候需要用configServer注入来使用这些参数）





# 购票

- 新建文件夹：ticket

- 理解下面的功能后需要用mysql-local帮我建立表
- 表由：购票_id(主键)、member_id(关联member表)、排场管理__id、购票时间、支付金额（这个由票数*排场管理.price构成）



## 接口



### 新增（购票）

- 购票的时候减去关联排场的剩余票数
- 可以选择购买票数
- 购票会先生成一条购票记录（有状态：未支付、已支付、已过期（如果十分钟内没有支付就会过期））
